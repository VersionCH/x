# Markdown 教程

Markdown 是一种轻量级标记语言。它使用简单的符号表示标题、列表、链接、代码等格式，纯文本也能保持良好的可读性，常用于写作、笔记、README 和博客文章。

## 一、标题

在文字前添加 `#` 即可创建标题，`#` 的数量代表标题级别，最多支持六级标题。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

建议从 `#` 开始按层级使用标题，不要为了调整字体大小而跳过层级。

## 二、段落与换行

Markdown 中直接换行通常仍属于同一段落。要开始新段落，需要在两段文字之间留一个空行。

```markdown
这是第一段。

这是第二段。
```

如果只想在同一段中换行，可以在行末添加两个空格，或者使用 HTML 的 `<br>` 标签：

```markdown
第一行  
第二行
```

## 三、文字样式

```markdown
**粗体文字**
*斜体文字*
***粗斜体文字***
~~删除线文字~~
`行内代码`
```

效果示例：**粗体**、*斜体*、***粗斜体***、~~删除线~~、`代码`。

## 四、引用

使用 `>` 创建引用，连续的 `>` 可以创建多层嵌套引用。

```markdown
> 这是一段引用。
>
> > 这是嵌套引用。
```

效果：

> 这是一段引用。
>
> > 这是嵌套引用。

## 五、列表

### 无序列表

使用 `-`、`*` 或 `+` 创建无序列表：

```markdown
- 苹果
- 香蕉
  - 小香蕉
  -大香蕉
- 橙子
```

### 有序列表

使用数字加英文句点创建有序列表：

```markdown
1. 准备材料
2. 开始制作
3. 完成检查
```

### 任务列表

使用 `[ ]` 和 `[x]` 创建任务列表：

```markdown
- [x] 学习标题和段落
- [x] 学习列表和链接
- [ ] 编写一篇文章
```

不同平台对任务列表的渲染支持可能略有差异。

## 六、链接

### 普通链接

```markdown
[GitHub](https://github.com)
```

也可以直接写链接：

```markdown
<https://github.com>
<example@example.com>
```

### 链接到页面内标题

大多数 Markdown 编辑器会根据标题生成锚点，可以使用标题文本跳转到页面内的对应位置：

```markdown
[跳转到文字样式](#三文字样式)
```

中文标题生成的锚点规则可能因平台而异，使用前应在目标平台测试。

## 七、图片

图片语法与链接类似，只需在前面加一个感叹号：

```markdown
![图片说明](https://example.com/image.png)
```

也可以指定图片标题：

```markdown
![图片说明](https://example.com/image.png "图片标题")
```

图片链接失效时，`![图片说明]` 中的文字会作为替代文本显示，因此建议始终填写有意义的图片说明。

## 八、代码

### 行内代码

使用一对反引号包裹短代码：

```markdown
请运行 `npm install` 安装依赖。
```

### 代码块

使用三个反引号包裹多行代码，并在开头标注语言名称，可获得语法高亮：

````markdown
```javascript
function greet(name) {
  return `你好，${name}！`;
}
```
````

常见语言标识包括 `javascript`、`typescript`、`python`、`bash`、`json`、`html` 和 `css`。

### 不指定语言

```text
这段代码不会进行语法高亮。
```

## 九、分隔线

单独一行使用三个或更多的 `-`、`*` 或 `_` 可以创建分隔线：

```markdown
---
```

效果：

---

## 十、表格

使用竖线 `|` 和短横线 `-` 创建表格：

```markdown
| 名称 | 类型 | 说明 |
| --- | --- | --- |
| Markdown | 语言 | 轻量级标记语言 |
| HTML | 标记语言 | 网页结构语言 |
```

可以使用冒号设置对齐方式：

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| A | B | C |
```

表格效果：

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| Markdown | 语言 | 轻量级标记语言 |
| HTML | 标记语言 | 网页结构语言 |

## 十一、转义特殊字符

如果需要显示 Markdown 的特殊符号，可以在符号前添加反斜杠 `\\`：

```markdown
\*这不是斜体文字\*
\# 这不是标题
\[这不是链接\]
```

常见需要转义的字符包括 `\\`、`*`、`_`、`#`、`+`、`-`、`.`、`!`、`[` 和 `]`。

## 十二、脚注

部分 Markdown 编辑器支持脚注语法：

```markdown
这是一段带脚注的文字[^1]。

[^1]: 这是脚注内容。
```

脚注并非所有平台都支持。如果目标平台无法正确渲染，可以改用普通链接或引用说明。

## 十三、HTML

Markdown 通常允许直接嵌入部分 HTML：

```html
<details>
<summary>点击展开</summary>

这里是折叠内容。

</details>
```

不过，不同编辑器对 HTML 的支持不完全一致。发布前应检查实际渲染效果，并注意不要嵌入不可信的脚本内容。

## 十四、常用写作建议

1. 使用清晰的标题组织文章结构。
2. 一段文字尽量只表达一个主要观点。
3. 链接文字应说明目标内容，不要大量使用“点击这里”。
4. 图片始终提供有意义的替代文本。
5. 代码块标注正确的语言，方便阅读和复制。
6. 发布前检查链接、图片、表格和移动端显示效果。
7. 记住：Markdown 的具体扩展功能取决于编辑器或网站平台。

## 总结

Markdown 的核心语法并不复杂：使用 `#` 表示标题，使用 `-` 或数字表示列表，使用 `[]()` 表示链接，使用反引号表示代码。掌握这些基础语法后，就可以编写结构清晰、易于维护的笔记和文章了。
